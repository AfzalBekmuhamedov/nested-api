Nested Category REST API

Nested Category REST API is a Django REST Framework project designed for platforms that require hierarchical category structures.

The API supports a structure consisting of main categories, subcategories, and catalog items such as products or other information.

It can be used as a backend structure for platforms where products or other catalog items are organized into categories and subcategories.

Structure

The project follows a hierarchical structure:

Category
→ Subcategory
→ Catalog / Product

For example:

Electronics
→ Smartphones
→ Product

Clothing
→ Shoes
→ Product

Features

- RESTFULL API
- Main Categories
- Subcategories
- Catalog Items
- Product/Data Management
- Category-based organization
- Nested category structure
- API endpoints

How It Works

The main category contains related subcategories.

Each subcategory can contain catalog items such as products or other information.

This structure allows client applications to retrieve and organize data according to the category hierarchy.
